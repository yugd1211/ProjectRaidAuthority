# 00_Plan

아직 실제 개발/운영 기준으로 채택되지 않은 기획·프로덕트·사업·기술 방향성 문서를 보관합니다.
현재 문서들은 원본 3개를 읽고 중복을 제거해 주제별로 분리한 **초안 상태**입니다.

## 하위 폴더

| 폴더 | 역할 |
|---|---|
| `00_Source` | 외부/다운로드 원본 보존 |
| `01_GameDesign` | 게임 컨셉, GDD Lite, 루프, MVP 범위 |
| `02_ProductPlan` | 기간 산정, 월별/주차별 로드맵, PM 운영 |
| `03_TechOps` | 서버 권위, 네트워크, 데이터, Docker, QA |
| `04_BusinessMarket` | 경쟁작, 타겟, BM, 사업 검증 |

## `01_InProgress`으로 이동하는 조건

- 해당 문서가 이번 주/이번 phase의 실제 판단 기준이 됨
- 문서 안의 checklist를 기준으로 개발, 검증, 또는 사업 판단을 진행함
- 팀/에이전트/사용자가 “이 문서를 기준으로 실행한다”고 명시함

## `02_Complete`으로 이동하는 조건

- 승인된 결정 기록으로 고정됨
- 다른 문서로 대체됨
- 폐기 결정이 내려짐
- 해당 phase가 끝나고 회고/검증이 완료됨
