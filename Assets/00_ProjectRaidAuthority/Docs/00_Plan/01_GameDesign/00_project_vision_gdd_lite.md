## 한 줄 정의

**탑다운 익스트랙션 레이드 구조에 로그라이크식 런 빌드 선택을 결합하고, 전투·인벤토리·탈출 결과를 서버 권위로 확정하는 4~8인 PvE 중심 멀티플레이 MVP.**

## 장르 결합

| 축 | 내용 | 이유 |
|---|---|---|
| 탑다운 슈팅 | 조준, 이동, 발사, 회피 중심 전투 | 1인 개발 기준 3D FPS보다 애니메이션/카메라/판정 범위를 줄일 수 있음 |
| 익스트랙션 | 입장→루팅→교전→탈출→결과 저장 | 성공/실패가 명확하고 서버 권위 포트폴리오 가치를 보여주기 좋음 |
| 로그라이크 런 빌드 | 레이드 중 특성/시너지/저주 선택 | 콘텐츠 양보다 규칙 조합으로 반복 변주를 만들 수 있음 |
| 서버 권위 멀티 | 서버가 전투/루팅/탈출/저장을 확정 | 치트 대응, 인벤토리 무결성, 운영 로그를 기술 차별점으로 제시 가능 |

## Core Loop

```text
레이드 입장
  → 탐색/루팅
  → 교전
  → 특성 선택
  → 탈출 선택
  → 결과 저장
  → 메타 해금
```

## Meta Loop

```text
성공 탈출
  → 프로필/창고 저장
  → 선택지/특성 풀 확장
  → 다음 레이드 준비
  → 더 높은 리스크 탈출 선택
```

## MVP 핵심 필수 범위

| 카테고리 | MVP 기준 |
|---|---|
| 맵 | 1개 |
| 세션 | 10~15분 레이드 |
| 플레이어 | 1~4인 우선, 4~8인은 확장 목표 |
| 무기 | 2개 아키타입 |
| 적 | 일반 2종 + 엘리트 1종 |
| 루팅 | 컨테이너/월드 드랍/시체 루팅 |
| 인벤토리 | 서버 소유권 기반 |
| 탈출 | 기본 탈출 1종 + 고위험 탈출 1종 |
| 특성 | 8개 |
| 시너지 | 4개 |
| 저주 | 3개 |
| 저장 | 탈출 성공 시 결과 Commit |
| 서버 | Dedicated Server |
| 운영 | Docker 실행, 이벤트 로그 |

## MVP 제외 항목

| 제외 항목 | 제외 이유 |
|---|---|
| 정식 PvP | 라그 보상/치트/밸런스 리스크가 MVP 범위를 초과 |
| 거래소 | 경제/DB/악용 대응 비용 증가 |
| 다중 맵 | 콘텐츠 제작량 과다 |
| 보스 다단계 패턴 | AI/애니메이션/밸런스 비용 증가 |
| 무기 개조 심화 | 인벤토리/밸런스 복잡도 증가 |
| 과금/BM 시스템 | MVP 검증 목적과 무관. 사업 검증 문서에서 별도 보류 |

## MVP 특성/시너지/저주 방향

| 묶음 | 기준 |
|---|---|
| 특성 | 서버가 판정하기 쉬운 출혈, 소음, 대시, 회복, 반동 교환 중심 |
| 시너지 | 태그 카운트 기반. 2개 달성 약효과, 4개 달성 강효과 |
| 저주 | 강한 보상 + 명확한 디버프. 서버 스탯/스폰/탐지 규칙으로 처리 |
| 고위험 탈출 | 배율 보상보다 “특성 선택 1회 추가” 또는 “전용 상자”처럼 경제 폭주가 작은 보상 선호 |

## 디렉터 관점 핵심 전복 포인트 후보

현재 문서들은 기능이 많아질 위험이 있습니다. 전복 포인트는 하나로 압축해야 합니다.

**후보:** “탈출 성공 여부만 저장하는 게임”이 아니라, **레이드 중 선택한 특성/저주가 탈출 루트와 보상을 바꾸는 서버 권위 런 계약 게임**으로 정의한다.

이 후보는 추가 시스템이 아니라 기존 익스트랙션의 탈출 결정을 “런 빌드와 계약”으로 전환하는 방향입니다.
