# 01_InProgress

현재 개발, 검증, 일정 산정, 사업 판단에 직접 사용 중인 문서를 둡니다.
기획/사업 문서는 코드 구현처럼 즉시 완료 처리하지 않고, 실제 주차나 검토 기간 동안 이곳에 유지할 수 있습니다.

## 권장 사용 방식

- `00_WeeklyProgress`: 이번 주 PM 목표, 체크리스트, 검증 로그
- `01_DecisionReview`: 아직 결론이 나지 않은 디렉터/사업/기술 의사결정

## 이동 원칙

문서를 이 폴더로 옮기는 순간, 그 문서는 단순 참고 자료가 아니라 **현재 실행 기준**입니다.
따라서 문서 상단에 다음을 기록합니다.

```text
상태: InProgress
시작일:
담당/판단 주체:
완료 또는 이동 조건:
```
