# ProjectRaidAuthority Docs

이 폴더는 **기획, 프로덕트 방향성, 사업 판단, 기간 산정, 운영/PM 문서**를 보관하는 프로젝트 문서 루트입니다.
기능 단위 구현 계획만을 위한 `.omx/plans`나 `.codex` 작업 지시와 분리해, 게임의 장기 방향성과 의사결정 근거를 보존합니다.

## 문서 상태 노드

```text
Docs/
├─ 00_Plan/   # 아직 실행/운영에 들어가지 않은 기획, 조사, 초안, 검토 대기 문서
├─ 01_InProgress/   # 현재 개발/검증/운영 판단에 사용 중인 문서
└─ 02_Complete/     # 승인 완료, 종료, 폐기, 대체된 문서
```

## 상태 이동 규칙

| 상태 | 의미 | 이동 조건 |
|---|---|---|
| `00_Plan` | 초안/검토/정리 단계 | 문서가 작성됐지만 아직 실제 개발·운영 기준으로 채택되지 않음 |
| `01_InProgress` | 실행 중/검증 중 | 해당 문서가 현재 주차 목표, milestone, gate, 의사결정 검토에 직접 사용됨 |
| `02_Complete` | 완료/폐기/대체 | 문서의 결정이 완료됐거나 더 이상 현행 기준이 아님 |

## 중요한 운영 원칙

- 단순 기능 구현 문서는 `Plan → InProgress → Complete`을 하루 안에 통과할 수 있습니다.
- **기획/사업/프로덕트 방향성 문서는 자동으로 빨리 넘기지 않습니다.**
- 1주일 플랜, 시장 검증, 디렉터 판단, MVP 범위 같은 문서는 실제 검토/실행 기간 동안 `01_InProgress`에 머물 수 있습니다.
- 문서를 이동할 때는 `.meta` 파일도 함께 이동해 Unity GUID를 유지합니다.
- 원본 자료는 `00_Plan/00_Source`에 보존하고, 정리본은 주제별 문서로 분리합니다.

## 현재 정리 기준

세 원본을 다음 기준으로 분리했습니다.

| 원본 | 분리 방향 |
|---|---|
| `pm_development_plan.md` | PM 로드맵, MVP 범위, 주차별 일정, 게이트 기준 |
| `deep-research-report.md` | 시장/장르 검증, 기술/운영 검증, 서버 모델, 리스크 |
| `30년차 시니어 게임 디렉터 prompt` | 디렉터 판단 프레임워크와 Codex skill |

## 현재 핵심 프로젝트 방향

**서버 권위 기반 탑다운 로그라이크 익스트랙션 4~8인 PvE 중심 멀티플레이 MVP.**

핵심 검증 순서는 다음과 같습니다.

```text
서버 권위 코어 → 전투 판정 → 인벤토리 무결성 → 레이드 완주 → 로그라이크 선택 → 운영/배포/QA
```
