# Raid 결과 화면

## 목적

결과 화면은 서버가 확정한 raid 결과를 보여준다. 플레이어는 무엇을 가져왔고, 무엇을 잃었고, 왜 성공/실패했는지 즉시 알아야 한다.

## 화면 구조

1. 결과 도장: 성공 / 실패 / 중단
2. 전리품 요약: 추출 성공 시 stash로 들어간 아이템
3. 잃은 것: 실패 시 보존되지 않은 raid loot
4. 전투 요약: 처치, 피해, 주요 event
5. 특성 요약: 선택한 trait/curse와 결과 영향
6. 서버 로그 요약: raid id, 주요 sequence, commit 여부

## 표시 규칙

- 성공 추출만 “보관됨”으로 표시한다.
- 실패한 raid loot는 “회수 실패”로 명확히 분리한다.
- 서버 commit event가 없으면 보상 확정 표현을 쓰지 않는다.
- 결과 화면의 숫자는 서버 결과 데이터에서만 온다.

## 아트 방향

- 더러운 계약서/영수증/서버 승인 도장 느낌을 사용한다.
- 성공은 warm yellow + cyan, 실패는 desaturated blue-gray + shame accent를 사용한다.
- 코미디는 문구보다 도장, 망가진 장비, 우스운 실패 아이콘으로 표현한다.

## 수용 기준

- [ ] 성공/실패가 한눈에 구분된다.
- [ ] 가져간 loot와 잃은 loot가 분리된다.
- [ ] 서버 commit 여부가 표시된다.
- [ ] raid id 또는 로그 참조값이 QA용으로 보인다.
