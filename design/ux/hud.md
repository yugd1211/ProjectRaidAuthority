# HUD 설계

## 목적

HUD는 서버가 확정한 raid 상태를 빠르게 보여주는 계약 단말기다. 예쁘게 꾸미기보다 HP, 탄약, 전리품, 추출 상태, 서버 확인 여부를 즉시 읽히게 한다.

## 주요 영역

| 영역 | 정보 | 규칙 |
|---|---|---|
| 좌상단 | HP, 상태이상 | 위험 상태는 색상+아이콘+짧은 텍스트 |
| 우상단 | 탄약, 무기 상태 | reload/불가 상태를 명확히 표시 |
| 하단 | 상호작용 prompt | 거리 부족, 이미 획득, 서버 확인 중 표시 |
| 중앙 주변 | hit/피해 피드백 | 짧고 강한 표시, 화면을 가리지 않음 |
| 우하단 | loot weight/value | 추출 전 임시 보상임을 구분 |
| 상단 중앙 | raid timer/extract 상태 | 서버 timer 기준으로 표시 |

## 서버 상태 표시

- 서버가 확정한 이벤트는 작은 도장/체크 형태로 보여준다.
- 클라이언트 예측 상태는 확정 상태와 시각적으로 구분한다.
- 서버가 거절한 행동은 원인을 짧게 표시한다.

## Broken Toy Raid Punk 표현

- 패널은 낡은 계약 단말기처럼 보이게 한다.
- cyan은 서버 확인, yellow/green은 loot, red/orange는 위험, magenta는 이상한 특성에 사용한다.
- 너무 많은 장식보다 비뚤어진 패널, 테이프, 경고색 한두 개로 충분하다.

## 수용 기준

- [ ] HP, ammo, raid timer, loot value가 1080p에서 읽힌다.
- [ ] 서버 거절 메시지가 1초 안에 이해된다.
- [ ] 색상 없이도 위험/loot/추출 상태를 구분할 수 있다.
- [ ] HUD가 탑다운 전투 시야를 과도하게 가리지 않는다.
