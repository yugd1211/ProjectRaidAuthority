# 상호작용 패턴

## 목적

플레이어가 loot, 문, terminal, extraction zone, trait offer와 상호작용할 때 서버 권한 상태를 명확히 이해하게 한다.

## 공통 패턴

| 상황 | 표시 | 서버 규칙 |
|---|---|---|
| 상호작용 가능 | 아이콘 + 테두리 + 짧은 동사 | 서버가 거리/상태를 최종 확인 |
| 상호작용 불가 | 회색 처리 + 이유 | 클라이언트 추정이어도 서버 거절을 우선 |
| hold interaction | 원형/막대 진행률 | 서버 timer 기준으로 완료 |
| 요청 중 | 작은 서버 확인 indicator | 중복 입력 방지 |
| 거절 | 짧은 원인 텍스트 | 로그 가능한 rejection reason 사용 |

## 입력 기준

- 기본 상호작용: `E`
- 길게 누르기: 위험한 loot, extraction hold, terminal 작동
- 취소: 이동 또는 `Esc`
- gamepad는 MVP 이후 검증

## 메시지 문구 기준

- “거리 부족”
- “이미 획득됨”
- “서버 확인 중”
- “추출 구역 유지”
- “전리품 확정 실패”

## 수용 기준

- [ ] 상호작용 가능/불가 상태가 구분된다.
- [ ] 서버 거절 사유가 표시된다.
- [ ] hold 진행률이 서버 결과와 어긋나지 않는다.
- [ ] 중복 입력이 UI상으로도 억제된다.
