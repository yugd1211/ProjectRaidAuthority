# 접근성 요구사항

## 상태

- **단계**: Basic + 일부 Standard 목표
- **목적**: MVP에서 최소한의 읽기성, 조작 가능성, 피드백 명확성을 확보한다.

## 기본 원칙

- 정보는 색상 하나에만 의존하지 않는다.
- 한국어 본문은 14px 이상을 기본으로 한다.
- 전투, loot, 추출, 실패/성공은 색상 + 아이콘/텍스트/모양을 함께 사용한다.
- 입력은 키보드/마우스 기준으로 명확히 설명한다.

## HUD 요구사항

- HP, ammo, extract timer, loot weight/value는 상시 읽혀야 한다.
- 위험 상태는 색상 외에도 아이콘과 짧은 텍스트를 제공한다.
- 서버 거절 메시지는 짧고 구체적이어야 한다. 예: “거리 부족”, “이미 획득됨”.

## 상호작용 요구사항

- 상호작용 가능 물체는 테두리, 아이콘, 색상 중 최소 두 가지 신호를 가진다.
- hold interaction은 남은 시간을 시각적으로 표시한다.
- 추출 구역은 범위와 진행률이 명확해야 한다.

## 시각 피드백 요구사항

- hit flash와 damage number는 배경과 충분히 대비되어야 한다.
- loot rarity는 색상만으로 구분하지 않고 아이콘/테두리/이름 표시를 함께 사용한다.
- 실패 화면은 짧고 명확해야 하며, 잃은 것과 보존된 것을 구분한다.

## 수용 기준

- [ ] 1080p 기준 HUD 주요 수치가 즉시 읽힌다.
- [ ] 색각 보정 없이도 상호작용 가능 물체를 구분할 수 있다.
- [ ] 추출 진행률과 실패 이유가 텍스트로도 제공된다.
- [ ] 키보드/마우스 입력 안내가 onboarding 또는 HUD에 표시된다.
