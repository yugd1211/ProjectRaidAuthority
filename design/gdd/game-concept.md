# 게임 콘셉트 — ProjectRaidAuthority

> **상태**: Pre-Production 기준 승인  
> **작성 기준일**: 2026-05-13  
> **원본**: `Assets/00_ProjectRaidAuthority/Docs/00_Plan`

## 개요

ProjectRaidAuthority는 Unity와 FishNet authoritative dedicated server를 사용하는 탑다운 PvE 우선 추출 로그라이트 MVP다. 플레이어는 짧은 raid에 들어가 전리품을 챙기고, 전투와 위험한 특성 선택을 거쳐 살아서 추출해야 한다.

## 핵심 약속

- 서버가 전투, 전리품, 추출, 특성, 결과 저장의 진실을 소유한다.
- MVP는 1인 개발 6개월 안에 검증 가능한 작은 데모를 목표로 한다.
- 첫 vertical slice는 1맵, 제한된 적/아이템/특성, 1–4인 협동 후보를 기준으로 한다.
- 콘텐츠 양보다 “서버 권한이 실제로 작동한다”는 증거를 우선한다.

## 플레이어 판타지

플레이어는 폐품으로 고친 장비를 들고 위험한 raid에 들어간다. 더 욕심내면 더 좋은 보상을 얻지만, 죽거나 추출에 실패하면 가져갈 수 없다. 전투는 명확하고 짧으며, 특성 선택은 강하지만 어딘가 나사 빠진 부작용을 품는다.

## 디자인 기둥

| 기둥 | 의미 | MVP 판정 기준 |
|---|---|---|
| 서버 진실 우선 | 중요한 결과는 서버가 확정한다 | 클라이언트 조작으로 전투/loot/추출을 확정할 수 없다 |
| 짧은 위험-보상 루프 | 한 판 안에서 욕심과 탈출을 반복 판단한다 | 추출 성공/실패가 명확한 결과 차이를 만든다 |
| 나사 빠진 빌드 | 특성과 저주가 웃기지만 전술적이다 | 최소한의 특성 조합이 전투/loot에 영향을 준다 |
| 러프하지만 읽히는 아트 | Synty/키트배싱/간단 생성물을 허용한다 | 실루엣과 색상 역할이 명확하다 |

## 대상 범위

- **플랫폼**: PC standalone / Steam 데모 우선
- **시점**: 탑다운
- **모드**: PvE 우선, 협동 후보
- **엔진**: Unity 6000.4.5f1
- **네트워크**: FishNet dedicated server
- **아트 방향**: Broken Toy Raid Punk

## 제외 범위

- PvP 중심 밸런스
- 대규모 오픈월드
- 모바일/콘솔 동시 대응
- 복잡한 경제/상점/live-ops
- 서버 권한 검증 전 콘텐츠 대량 생산

## 성공 기준

- 서버 권한 smoke prototype이 실제로 동작한다.
- 전투, 전리품, 추출, 결과 저장 중 핵심 흐름이 서버 로그로 검증된다.
- 한 판의 시작→전투/loot→추출→결과 화면 흐름이 끊기지 않는다.
- 1인 개발자가 유지 가능한 범위로 콘텐츠가 제한된다.
